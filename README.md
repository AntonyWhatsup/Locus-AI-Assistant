## 📖 Origin Story

Locus was originally conceived as a university project for a "Neural Networks" course. 
The core vision was to bridge the gap between complex technology and everyday users, specifically focusing on accessibility. 
The goal was to create a tool that simplifies device interaction and empowers individuals with special needs through intuitive voice control.

The name **Locus** was suggested by a colleague. Derived from Latin, it translates to **"place."** 
This reflects the project's philosophy: using the human voice to "point" the system toward the specific digital or physical "place" where an action is required. 
What started as an academic assignment has evolved into a mission to make technology more inclusive and human-centric.
